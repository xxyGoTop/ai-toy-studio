# Printing on Bambu Lab A1

## Workflow (V1)

1. Export STL from studio after mesh check
2. Open Bambu Studio
3. Choose Bambu Lab A1 profile
4. Select 0.4mm nozzle and PLA/PETG/TPU
5. Preview supports, walls, infill
6. Human confirm
7. Send print
8. Inspect first layer and final part

## Starting PLA profile

| Param | Start value |
|-------|-------------|
| Layer height | 0.16–0.20 mm |
| First layer | 0.20 mm |
| Walls | 3 |
| Infill | 10–15% |
| Top/Bottom | 4–5 |
| Supports | as needed |

## Safety

AI models must not go to print without:

- size normalization
- mesh check
- slicer preview
- human confirmation
